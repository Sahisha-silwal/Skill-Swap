SkillSwap is a full-stack web application designed to facilitate peer-to-peer skill exchanges through structured profile management and interactive match generation. Built with a React and Vite frontend, styled using Tailwind CSS, and backed by Supabase for database management and authentication, the platform allows users to manage their profiles securely. Users can specify skills they can teach, skills they wish to learn, spoken languages, and personal interests, all synchronized in real time via Supabase `upsert` operations. Protected by Row-Level Security (RLS) policies and integrated with backend API routes for fetching matching profiles, the application delivers a responsive and scalable platform for collaborative learning.
